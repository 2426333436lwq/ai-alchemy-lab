第一次看到 DeepSeek 官方定价页的时候，我们以为自己看错了单位。

**缓存命中的输入 token：每百万 $0.003。**

再写一遍：**0.003 美元**。按现在的汇率，差不多是两分钱人民币买一百万个 token。

作为对比：GPT-6.1 Sol 缓存后输入 $0.10，Claude Opus 5.5 缓存读价 $0.20。DeepSeek 是它们的**三十分之一到七十分之一**。

这不是打价格战，这是把 API 定价做成了一份**电价套餐**——它有峰时和闲时。

## 一个比喻：它把 API 做成了「分时电价」

很多地方的电费分峰谷：白天贵，深夜便宜。你不知道的话，白天洗衣服洗碗烧热水一起开，月底看着账单心疼；你知道的话，把热水器定时到半夜，同样的电省一半。

DeepSeek 的定价就是这个逻辑：

| 项目 | 峰时 | 闲时 | 差 |
| --- | --- | --- | --- |
| V4.1-Flash 输入（未命中缓存） | $0.30 | **$0.15** | 闲时半价 |
| V4.1-Flash 输出 | $1.20 | **$0.60** | 闲时半价 |
| V4-Pro-0813 输入（未命中缓存） | $1.32 | **$0.66** | 闲时半价 |
| V4-Pro-0813 输出 | $3.96 | **$1.98** | 闲时半价 |

而「峰时」的定义是这样的（按 DeepSeek 官方说明）：

> **UTC 时间周一至周五 01:00–04:00 与 06:00–10:00**，中国法定节假日除外；其余时间（含**周末全天**）均为闲时。

换算成北京时间，就是 **09:00–12:00 和 14:00–18:00**。

请特别注意这句话的含义：**如果你是一支在中国工作的团队，你的正常工作时间正好是它的峰时。** 白天调试、白天跑批处理，全都按双倍价结算。

但同时，这也意味着一件极爽的事：

> **周末全天、节假日全天、以及每天下班到第二天上班之间，你能拿到半价。**

顺手把两个容易被忽略的规格拉出来说：

- **384K 输出上限。** 别家前沿模型普遍给到 64K–128K，DeepSeek 给到 384K。如果你的产品要生成长报告、长代码文件，这一条直接决定了「要不要分段拼接」。
- **两种思考模式。** 支持思考与非思考模式，默认思考。而且——**思考过程会通过 `reasoning_content` 字段单独返回**，这对算账极其友好：你能直接看出「草稿费」占了多少。

还有一个几乎没人提、但工程上极有价值的事实：

> **DeepSeek 同时提供 OpenAI 格式（`https://api.deepseek.com`）和 Anthropic 格式（`https://api.deepseek.com/anthropic`）的接口。**

也就是说，**你现有的 Claude 客户端改一下 base_url 就能切过去**，代码一行不用动。

## 迁移成本为零，这是它最大的隐藏优势

```python
from openai import OpenAI

# 从别家切过来：只改 api_key 和 base_url，下面的调用代码一个字不用动
client = OpenAI(
    api_key=DEEPSEEK_API_KEY,
    base_url="https://api.deepseek.com",
)

resp = client.chat.completions.create(
    model="deepseek-flash",
    messages=[
        {"role": "system", "content": SYSTEM},   # 稳定不变 → 缓存命中 → $0.003/M
        {"role": "user", "content": question},
    ],
)

msg = resp.choices[0].message
print("草稿（思考）占了多少 token：", msg.reasoning_content)  # 单独返回，方便核算
print("正文：", msg.content)
```

这就是为什么我们在给团队做降本建议时，**总是把「先试 DeepSeek」排在第一位**：试错成本几乎为零，代码不用改，跑 100 条自己的数据两小时就能出结论。

## 算一笔账：同样的活，差十六倍

还是沿用在第 1 篇里那个场景：**每月 1000 万输入 token（其中 70% 命中缓存）、200 万输出 token。**

| 方案 | 输入费 | 输出费 | 月账单 |
| --- | --- | --- | --- |
| GPT-6.1 Sol（未错峰） | 300 万×$2 + 700 万×$0.10 = $6.7 | 200 万×$10 = $20 | **$26.7** |
| DeepSeek V4-Pro（闲时） | 300 万×$0.66 + 700 万×$0.022 = $2.13 | 200 万×$1.98 = $3.96 | **$6.09** |
| DeepSeek V4.1-Flash（峰时） | 300 万×$0.30 + 700 万×$0.006 = $0.94 | 200 万×$1.20 = $2.40 | **$3.34** |
| DeepSeek V4.1-Flash（闲时） | 300 万×$0.15 + 700 万×$0.003 = $0.47 | 200 万×$0.60 = $1.20 | **$1.67** |

**最贵和便宜相差约十六倍，而 Flash 闲时那一档每月只要一块六。**

一块六。这已经到了「**优化它的成本比优化别的东西还贵**」的程度——所以我们的建议是：**到这个价位就别再抠了，把精力花在 Prompt 和缓存命中率上更有性价比。**

## 上手：三件立刻能做的事

### 一、把批处理任务排到闲时

```python
from datetime import datetime, timezone, timedelta

CNTZ = timezone(timedelta(hours=8))
PEAK = [((9, 0), (12, 0)), ((14, 0), (18, 0))]   # 北京时间峰时区间

def is_peak(now: datetime | None = None) -> bool:
    now = (now or datetime.now(CNTZ)).astimezone(CNTZ)
    if now.weekday() >= 5:            # 周末：全天闲时
        return False
    t = (now.hour, now.minute)
    return any(a <= t < b for a, b in PEAK)
    # 注：中国法定节假日全天闲时，实际请自行判断是否需叠加节假日日历

# 用到地方：夜间的离线批任务挂到闲时 queue 里跑，同样的工作半价
if not is_peak():
    run_batch_jobs()
else:
    queue.defer(run_batch_jobs)      # 攒着，等闲时
```

我们的做法是：**所有离线批处理（批量生成、 overnight 报告、数据清洗）统一挂到闲时队列**，在线请求照常跑。光这一条，离线部分的账单直接腰斩。

### 二、把长文本的系统提示词锁死

缓存命中与否的差别是 **$0.15 和 $0.003，差了 50 倍**。而缓存命中的前提是：**请求前面那一段完全一致。**

所以：少在系统提示词里塞日期时间戳，少拼随机数，工具定义和 Few-shot 示例全部前置且保持不动。

### 三、注意并发上限

Flash 并发 2500、Pro 并发 500。如果你打算把全站流量都压过来，这是**比价格更早会撞到的墙**——先用灰度的方式切一部分流量过去试试。

## 必须说的实话：「开源」不等于「你能跑得起」

这一点我们一定要讲清楚，因为这个误解很贵。

DeepSeek 的权重确实是 MIT 许可开放下载的。但：

- **V4-Pro 总参数约 1.6 万亿**（MoE，激活约 490 亿）——这是明确的数据中心级负载，不是你机房里那两台机器能扛的；
- **V4-Flash 总参数约 2840 亿**（激活约 130 亿），在混合精度下权重仍然是一百多 GB 量级，重度量化也要几十 GB——意味着**多卡服务器，而不是一台台式机**。

所以正确的判断逻辑是：

> **决定自部署之前，先算三样东西：GPU 采购或租用费、电费、运维人力。**
> 对绝大多数团队而言，**按 API 调用反而比自建便宜**——除非你有强制的数据不出境要求，或者调用量大到足以让机器 7×24 打满。

另外提醒：**V4-Pro 不支持视觉输入，只有 Flash 支持。** 如果你的多模态需求是刚性的（看图、读图），别选 Pro。

还有一条历史信息：**老的 `deepseek-chat` 和 `deepseek-reasoner` 已经停止服务**。虽然旧名字还可能被路由到 Flash，但请尽快迁移到 `deepseek-flash` / `deepseek-v4-pro` 这两个新名字，别在新项目里再写老字符串。

## 炼丹小结

1. DeepSeek 的杀手锏是**峰谷定价**：闲时半价，而**周末全天、节假日全天、下班后到上班前**都是闲时。
2. **缓存命中 $0.003/M**，与未命中相差 50 倍——把系统提示词锁死是收益最高的一步。
3. 同时提供 **OpenAI 格式与 Anthropic 格式**接口，迁移几乎零成本，这是被严重低估的优势。
4. 1M 上下文、**384K 输出上限**（远超别家），思考内容单独在 `reasoning_content` 里返回，方便核算「草稿费」。
5. **开源 ≠ 能自己跑**：V4-Pro 1.6T 参数、V4-Flash 284B 参数，都是多卡服务器级别；先算 GPU + 电 + 运维再决定自建。
6. Pro 不支持视觉、并发上限 500，这两个要提前排进设计。
