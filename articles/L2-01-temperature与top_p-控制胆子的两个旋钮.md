同一个 Prompt，第一次答得挺好，第二次就跑偏了。很多人以为是模型"抽风"。

其实是你没调两个旋钮：**temperature** 和 **top_p**。它们控制的是模型"敢不敢冒险"。

## 先记住一个画面：抽奖转盘

回顾第一层：模型每一步都是在**猜下一个字**，而它对每个候选字都有一个概率。

假设现在要接"床前明月光，"的下一句，它脑子里可能是：

| 候选 | 概率 |
| --- | --- |
| 疑是地上霜 | 82% |
| 疑似地上霜 | 9% |
| 地上白茫茫 | 4% |
| ……（几千个其他候选） | 剩下 5% |

**temperature 决定的，就是这个转盘怎么转：**

- **temperature 低（比如 0.1）**：把概率"压尖"——82% 变成 98%。转盘上"疑是地上霜"那一格巨大无比，几乎必中。**输出稳定、保守、重复率高。**
- **temperature 高（比如 1.0）**：把概率"拉平"——82% 变成 30%，候选们差不多大。冷门选项有机会中。**输出多变、有创意、也更可能胡说。**

> 一句话：**temperature 就是模型的胆子。** 越小越怂（只敢说最安全的话），越大越浪（什么都敢接）。

## top_p 是另一个思路

top_p（又叫核采样）不看概率怎么分布，它做的是**砍尾巴**：

> 把所有候选按概率从高到低排，只保留累计概率达到 p 的那一小撮，剩下的**全部丢掉**，然后在这小撮里选。

比如 `top_p = 0.9`：从"疑是地上霜"(82%) 开始累加，加上 9% 到 91%，够了，停。**后面几千个冷门候选全部出局。**

| 参数 | 调的是什么 | 大白话 |
| --- | --- | --- |
| temperature | 概率分布的**形状** | 让冷门选项有没有机会中 |
| top_p | 候选池的**大小** | 把明显不靠谱的尾巴砍掉 |

**两者通常只调一个就够了。** 社区里更常见的做法是：**固定 top_p（比如 0.9），主要调 temperature**。

## 该拧到几：一张速查表

| 任务类型 | temperature | 说明 |
| --- | --- | --- |
| 数学计算、代码生成 | 0 ～ 0.2 | 要的是唯一正确答案，别发挥 |
| 信息抽取、分类、格式转换 | 0 ～ 0.2 | 要稳定，不要创意 |
| 日常问答、总结、翻译 | 0.3 ～ 0.7 | 平衡点 |
| 写作润色、客服话术 | 0.7 左右 | 要一点自然变化 |
| 头脑风暴、起名字、写小说 | 0.8 ～ 1.2 | 这时候就要它浪 |

**判断标准就一条**：这个任务有没有"唯一正确答案"？

- **有**（数学、代码、抽取）→ 胆子调小；
- **没有**（创意、文案）→ 胆子调大。

## 动手试试

装了 Ollama 的话（见《本地跑一个 7B 模型》），直接对比：

```bash
# 保守模式：适合让它写代码
ollama run qwen2.5:7b --temperature 0.1 --top-p 0.9
>>> 用 Python 写一个快速排序

# 放飞模式：适合让它想点子
ollama run qwen2.5:7b --temperature 1.0 --top-p 0.95
>>> 给一家咖啡店想 10 个名字
```

同一个 Prompt 在两个模式下各跑三次，**观察输出的差别**。这个体感比记表格有用得多。

如果用 API：

```python
response = client.chat.completions.create(
    model="your-model",
    messages=[{"role": "user", "content": prompt}],
    temperature=0.2,   # 要准确 → 调低
    top_p=0.9,         # 一般不用动
)
```

## 三个常见误区

### 误区一：「temperature=0 就一定每次一样」

**不一定。** 理论上 0 表示永远选概率最高的那个，但浮点计算、批处理调度等工程因素仍可能带来微小差异。

> 需要严格可复现时（比如做评测），别只依赖 temperature=0，要在你的评测流程里做多次采样取一致结果，或固定随机种子（若接口支持）。

### 误区二：「调高 temperature 能治好幻觉」

**恰恰相反。** 高温 = 更敢选冷门 = **编造概率更高**。

模型胡说八道的时候，正确的动作是**调低 temperature + 给它资料**（见《幻觉》和 RAG），不是调高。

### 误区三：「temperature 可以超过 1 就一直往上加」

超过 1 之后输出会迅速变得语无伦次——它在大量选那些"几乎不可能"的字。创意任务一般到 1.0～1.2 就够，再高就是噪音。

## 炼丹小结

1. **temperature = 模型的胆子**：低了保守稳定，高了创意但易胡说；
2. **top_p = 砍掉不靠谱的尾巴**，一般固定在 0.9 不用动；
3. 判断标准：**有唯一正确答案的任务调低，没有的调高**；
4. 它胡说时**调低**而不是调高；
5. temperature=0 也不保证百分百可复现，做评测要注意。

调好这两个旋钮，你的输出就从一个"时好时坏的抽奖"，变成了"可控的工具"。
