先做个小实验。打开任意模型问它：

```text
strawberry 里有几个字母 r？
```

很多模型会答 2 个。正确答案是 **3 个**（st**r**awbe**rr**y）。

这不是因为模型笨。**是因为它压根没看到字母。**

## 模型眼里的文字：一块一块的，不是一个一个的

我们读 "strawberry" 是一个字母一个字母地看：s-t-r-a-w-b-e-r-r-y。

模型看到的是**预先切好的块**，比如：

```text
"strawberry"  →  ["straw", "berry"]      或者  ["str", "aw", "berry"]
```

这些块就叫 **token**。模型的所有工作——读、想、写——都是在块的层面上进行的。

所以你问它"有几个 r"，它面对的是两个块 `straw` 和 `berry`，它得**猜**这两个块里一共几个 r——而猜，是会错的。

## 中文也是一样

中文的切法常常比中文更有意思：

```text
"人工智能"  →  ["人工", "智能"]      ← 常见切法
"我喜欢吃火锅"  →  ["我", "喜欢", "吃", "火锅"]
```

你会发现：**常见的词会被合并成一个 token**，不常见的词才会被拆碎。

这带来一个反直觉的现象：

> 同一个意思，用常见的说法写，比用生僻说法写**更省 token、模型也更好理解**。

因为它脑瓜里存的是"人工"+"智能"这两个熟人，而不是零散的笔画。

## 为什么这件事很重要：三个直接影响

### 1. 钱是按 token 算的，不是按字数

你调用 API 付费，账单上是输入 token 数 + 输出 token 数。

**大致的经验值**（不同模型的分词器不一样，仅供估算）：

| 内容 | 大约多少 token |
| --- | --- |
| 1 个英文单词 | 约 1.3 个 token |
| 100 个英文单词 | 约 130 个 token |
| 100 个汉字 | 约 70～150 个 token（看分词器和用词） |

所以：**同样一段话，中文往往比英文"贵"一些**；而同样的中文，用词常见与否也会影响 token 数。

### 2. 上下文窗口是按 token 算的

你常听到"这个模型支持 12.8 万 token 上下文"——**不是 12.8 万字**。

按上面的估算，12.8 万 token 大约是一本十几万字的书。对话聊长了、资料塞多了，都会把这个额度吃光。

（为什么"塞满"不是好事，第二层《上下文窗口》会细讲。）

### 3. 它解释了模型的一类"低级错误"

除了数 r，还有这些经典翻车：

| 任务 | 为什么容易错 |
| --- | --- |
| 数某个字母出现几次 | 它看到的是块，不是字母 |
| 倒着念一个单词 | 它从不"反着看"文本 |
| 判断两句是否押韵 | 押韵看发音，它只看到拼写块 |

**实用结论**：凡是"逐字符操作"的活儿，别指望模型直接干。让它**写代码去干**，代码是逐字符的，模型不是。

```text
❌ 「这个字符串里有多少个大写字母？」   → 它可能猜错
✅ 「写一段 Python 统计这个字符串里的大写字母数量，并只输出数字。」
   → 交给解释器执行，100% 准确
```

## 亲手看看 token 长什么样

如果你装了 Python，可以装个分词器自己看（以常用的 GPT 系分词器为例）：

```bash
pip install tiktoken
```

```python
import tiktoken
enc = tiktoken.get_encoding("cl100k_base")

for s in ["strawberry", "人工智能", "我喜欢吃火锅"]:
    ids = enc.encode(s)
    print(s, "→", ids, "→", [enc.decode([i]) for i in ids], f"共 {len(ids)} token")
```

你会亲眼看到每个词被切成了什么。**这个体验比读十遍解释都管用。**

## 炼丹小结

1. **token 是模型读写的最小单位**，不是字，也不是字母；
2. 常见词合成一个 token，生僻词被拆碎——所以**用词越常规越省**；
3. 计费、上下文长度，全都按 token 算；
4. 数数字母、倒着念这类"逐字符"任务，**让模型写代码去执行**，别让它硬猜；
5. 下次看到"支持 20 万 token 上下文"，记得换算一下，那**不是 20 万字**。

理解了 token，你就知道了模型这个"工作台"的计量单位。下一层讲 RAG 和上下文窗口时，你会反复用到它。
