通义千问 Qwen：货架最宽的那家铺子

2026 年 9 月 27 日约 11 分钟炉具评测 模型选型 通义千问 Qwen 阿里云百炼 成本优化

逛完前面几家，你会发现一个规律：它们的打法都是「一个旗舰打天下」——一个最强的模型撑门面，往下切几档。

但通义千问不是这个路数。它像一家仓储超市。

货架从几毛钱的小件一路排到整套餐。因为阿里卖的不只是「模型」，而是一整个模型层：Max / Plus / Flash 三档闭源商用型号，加上一大批可直接拉取权重的开源型号，外加语音识别、语音合成、图片理解、视频生成，全部在同一个账号体系里。

所以这一篇的重点不是「Qwen 哪个最强」，而是：这家店该怎么逛。

先分清楚两个货架

这是最容易搞混的一点。Qwen 同时有两个产品线，它们的价格体系完全不同：

闭源商用货架 开源权重货架
型号命名 Qwen3.8-Max、Qwen3.8-Flash、Qwen3.7-Plus qwen3.5-397b-a17b、qwen3.5-35b-a3b、qwen3.5-27b
拿得到权重吗 拿不到 能自己下载部署
计价币种 人民币（¥/百万 token） 国际站美元（$/百万 token）
适合谁 直接用、不想运维 要微调、要私有化、量大到自建更划算

混为一谈的话，你的成本估算会全错。

货架 A：闭源商用型号（核对时间：2026 年 10 月初）

单位：人民币元 / 百万 token。以下为阿里云官方页面标注的原价，实际常有折扣与资源包，按下单前控制台为准。

Qwen3.8-Flash ¥0.8 ¥2.7 ¥0.1 ¥0.4 / ¥1.35
Qwen3.7-Plus（≤256K） ¥2.4 ¥9.6 — —
Qwen3.7-Plus（256K–1M） ¥7.2 ¥28.8 — —

只看最便宜的 Qwen3.8-Flash：¥0.8 / ¥2.7，换算成美元约 $0.11 / $0.39。这个价格和 Gemini 2.5 Flash-Lite（$0.10/$0.40）几乎是一模一样的——国产的最低档已经和国际最低档对齐了。

一个「显式缓存」的小门道

Qwen3.8-Max 还有一个别家不太常见的计费项，值得单独讲：

项目 价格
普通输入 ¥12/M
显式缓存创建 ¥15/M
显式缓存命中 ¥1/M

意思是：你可以主动花 ¥15/M 把一段前缀「钉」进缓存，之后每次读它只要 ¥1/M。

划算吗？算一下。假设同一段前缀要用 N 次：

  • 不用缓存：N × ¥12
  • 用显式缓存：¥15 + N × ¥1

两者相等时 N ≈ 1.36，也就是说——同一个前缀只要重复用到第 2 次，显式缓存就开始赚钱了。

这个玩法特别适合「一份超长的产品文档 / 规范，配 N 个不同用户提问」这种场景。别忘了打开。

注意那个命名里的规律：397b-a17b 的意思是「总参数 3970 亿、激活 170 亿」，35b-a3b 就是「总 350 亿、激活 30 亿」——这是 MoE（混合专家）的写法，和第 5 篇讲的 DeepSeek、第 7 篇讲的 GLM 是同一套思路：总参数大，但每次只唤醒一小部分，所以用起来便宜。

看这张表最有用的一个角度是：qwen3.5-35b-a3b 的输入价 $0.057，是我们这一系列里最便宜的一档之一——而它确实是一个可以自己下载、跑在几张消费级显卡上的小模型。

Qwen 真正独占的优势：模态全家桶

别的厂商做多模态，通常是「主模型 + 几个附属型号」。Qwen 做的是一整条流水线：

能力 型号 说明
全模态理解 Qwen3.5-Omni（Flash / Plus） 文本、图片、音频、音视频理解与交互，同一个模型
图片 / 视频理解 Qwen3-VL 系列 看图、读图表
语音合成 Qwen3-TTS-Flash 官方称 17 种拟人音色，支持同音色多语言输出
语音识别 Fun-ASR-Realtime 实时 ASR，带 ITN 规范化、语气词过滤
视频生成 万相 Wan2.7 支持图生视频、参考生视频、音视频混合参考

这意味着一件事：如果你在做一个「带语音的产品」（比如电话客服、语音助手、有声内容生成），Qwen 是唯一能让你在一家厂商内走完全链路的选择。

换个今天都还是痛点的例子：你要做一个「用户对着 App 说话 → 转成文字 → 理解意图 → 用同一个音色回答」的功能。在其他家，你要拼两家甚至三家的服务，中间还要处理鉴权、计费、日志对齐；在 Qwen 这边，同一个 key，同一份账单。

这份「整合度」在日常 pilot 阶段的价值，比单点的性能差距大得多。

上手：一个账号逛完两个货架

阿里云百炼的 API 是 OpenAI 协议兼容的（地域不同 endpoint 会变，国际站请用控制台给出的实际地址）：

from openai import OpenAI

client = OpenAI(
    api_key=DASHSCOPE_API_KEY,
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
)

resp = client.chat.completions.create(
    model="qwen3.8-flash",        # 便宜档：¥0.8 / ¥2.7 每百万 token
    # model="qwen3.5-397b-a17b",  # 开源货架那个大家伙：$0.172 / $1.032
    messages=[
        {"role": "system", "content": SYSTEM},   # 想要省钱就用显式缓存钉住这段
        {"role": "user", "content": question},
    ],
)
print(resp.choices[0].message.content)

如果你已经读到第三层学过了微调（第 9、10 篇），这里还有一条很顺的衔接：百炼支持直接部署你自己做好的 LoRA 微调产物（通过 token 部署，指定 plan=lora）。也就是说：

你在本地或平台上用 LoRA 微调出一个「说话很像你们公司」的版本，训练完不用自己搭推理服务，直接托管上去就能有稳定的 API 地址。

这中间省掉的运维成本，对大多数小团队来说是实实在在的一笔钱。

另外还有 PTU / 吞吐量预留（Throughput Reservation） 这一档：给定的 TPM 额度按天/按月包月，适合那种「必须保证高峰期不被限流」的生产场景。清单里也包括 DeepSeek、GLM、Kimi 等其他厂商的型号——阿里云实际上在做国产模型的「集成商」，这一点很值得注意。

什么时候别逛这家店

  • 你的题目需要最顶级的推理能力 → Max 档的存在是为了给国内场景一个强选项，但把它和国际顶格档横向比排行榜，请在你自己的数据上做，别只看宣传材料。
  • 你主要在海外、且要有最优的选择自由度 → 开源货架是国际站报价（美元），看不到国内价格体系；这种情况直接用 DeepSeek / GLM 的国际版价格比较更直观。
  • 你的 Prompt 极其依赖某个海外模型的「说话方式」 → 换模型的迁移成本在第 1 篇讲过，别低估。

炼丹小结

  1. Qwen 是两个货架：闭源商用（人民币计价）与开源权重（国际站美元计价），混着算钱一定算错。
  2. 最低档 Qwen3.8-Flash ≈ $0.11/$0.39，已经和国际最低档完全对齐。
  3. 显式缓存是一个被低估的功能：创建 ¥15/M、命中 ¥1/M，同一个前缀用到第 2 次就开始回本。
  4. 命名规则 397b-a17b = 总参数 3970 亿 / 激活 170 亿，这是 MoE 的标准写法，看懂它就能自己估推理成本。
  5. 全模态是 Qwen 真正的护城河：Omni 理解 + TTS + ASR + 视频生成在同一账号下，语音类产品可以一条链路走完。
  6. 顺手记一下：百炼可以直接托管 LoRA 微调产物，还能做 PTU 吞吐量预留，适合害怕被限流的生产场景。
