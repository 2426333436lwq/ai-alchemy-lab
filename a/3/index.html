本地跑一个 7B 模型：平民炼丹指南

2026 年 9 月 27 日约 2 分钟大模型 LLM 教程

总觉得炼丹是卡大户的专利？其实一口小炉也能开火。

这篇笔记带你在自己的电脑上跑起一个 7B 级别的开源模型，全程大约十分钟。

准备工作

  • 一台内存 16GB 以上的电脑（有 8GB 以上显存的显卡更佳）；
  • 一个命令行终端；
  • 一点点耐心。

第一步：安装 Ollama

Ollama 是目前最省心的本地模型运行器，支持 macOS、Linux 和 Windows。

# macOS / Linux
curl -fsSL https://ollama.com/install.sh | sh

Windows 用户直接在官网下载安装包即可。

第二步：拉取模型

以 Qwen2.5 7B 为例：

ollama pull qwen2.5:7b

4bit 量化后大约 4.7GB，家用宽带几分钟能下完。

第三步：开火对话

ollama run qwen2.5:7b

看到 >>> 提示符，你的小丹炉就算点着了。试着问一句：

>>> 用一句话解释什么是注意力机制

性能参考

设备 速度 体验
M2 MacBook Air 16GB 约 20 token/s 流畅
RTX 3060 12GB 约 35 token/s 舒适
纯 CPU（8 核） 约 5 token/s 能跑，适合深夜静思

炼丹小结

  1. 7B 模型是家用炉的「经济适用丹」：够用、好养、不炸炉；
  2. 量化是平民炼丹的核心科技，4bit 量化让显存需求降到原来的四分之一；
  3. 本地模型适合隐私场景和离线场景，但别指望它打赢云端的大炉。

丹不分大小，炼起来就是好的。
