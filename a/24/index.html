GLM 与智谱：从价格战里第一个涨价的那家

2026 年 9 月 27 日约 11 分钟炉具评测 模型选型 GLM 智谱 Zai 国产模型 开源模型

我们先讲一个故事。

2026 年上半年，整个大模型市场在打价格战。DeepSeek 把价格砍到地板，一家接一家厂商跟进降价，「一毛钱一百万 token」的宣传语满屏都是。

然后——2026 年 2 月，GLM（智谱）涨价了。

据公开报道，智谱当时对旗舰模型 GLM-5 的接口计费及 Coding Plan 做了调整，受算力供需关系紧张影响，累计涨幅约 30% 到 83% 不等。报道里的那句评价写得很到位：

率先宣告行业从价格战回归价值定价。

这一篇我们就从这个反直觉的决定讲起。

一个比喻：它不想做路边摊

价格战的逻辑是「先用便宜把你吸引过来，再谈别的」。这条路走到极致就是当年的免费网盘大战——用户是来了，但谁都不赚钱，服务一限速就崩盘。

GLM 走的是另一条路：做体制内的餐厅。 不一定最便宜，也不一定最好吃，但资格审查最齐、出问题有人负责、你能签正式合同。

翻译成技术选型语言：

GLM 的卖点不是单点的「最强」或「最便宜」，而是「开源到可私有化」+「国内合规完整」+「1M 长上下文的 Agent 耐力」这三条同时成立。

型号与价格：两条报价轨道要分清

国内外双轨这一点跟第 6 篇的 Qwen 很像，但 GLM 更明显——国内站（open.bigmodel.cn，人民币）和国际站（docs.z.ai，美元）是两个价格体系。

所以做成本估算时有一条硬规则：

在 GLM 上，短请求非常便宜，超过 32K 的长请求要单独算。 如果你的用法是「每次塞一大段材料」，别拿那个 ¥4 的标价去估算。

这些数字放在一起有一个很清晰的指向：GLM 的强项是「写代码」和「用工具」，也就是 Agent 相关能力，而不是纯粹的知识问答。

这跟智谱自己的产品定位是对应的——他们一直在推 Coding Plan，明显是针对「模型在你 IDE 里连续干好几个小时」这种场景做的优化。

GLM 的三张牌

第一张：开源到真的能拿走

GLM 的权重放在 Hugging Face 的 zai-org 组织下开放下载。尺寸梯度也比一般厂商铺得细：

型号 参数结构 处境
GLM-5 系列 总参数约 7440 亿量级 数据中心级，别想单机跑
GLM-4.5-Air 1060 亿总 / 120 亿激活 多卡服务器
GLM-4.7-Flash 310 亿总 / 30 亿激活 单卡可跑，而且 API 免费

最后一行是很多人没注意到的宝藏：GLM-4.7-Flash 是一个 31B/3B 的 MoE，激活参数只有 30 亿，意味着它在消费级显卡上跑得动，而 API 调用还是免费的。

（关于开源≠能自己跑的老话题，第 5 篇 DeepSeek 那篇讲过一遍，原则一样：先算 GPU + 电 + 运维。）

第二张：1M 上下文 + Agent 耐力

GLM-5.3 / 5.2 / 5.1 三档都给到了 1M 上下文、128K 输出上限。

而且 GLM-5.3-Flash 除了便宜（$0.15/$0.50），还原生支持图片、视频、文件的直接上传（API 侧支持 JPEG / PNG / WebP，单文件约 4MB 上限）。

这意味着一件事：GLM-5.3-Flash 是我们这一系列里扫到的、最便宜的「能吃视频和文件」的方案。 如果你的场景是「丢一个屏幕录制视频给它，让它讲讲里面发生了什么」，它的性价比非常夸张。

第三张：国内合规 + 落地路径

智谱是国内体系里落地路径最完整的一家之一：本地化的合同、发票、等保 / 合规材料、企业级支持，加上开源权重可以私有化部署。

对很多政企场景来说，「能不能给我一份签字盖章的承诺书」比「benchmark 高 2 分」重要一百倍——这时候 GLM 的价值才能体现出来。

（顺带一提：GLM-Image 出图约 $0.015 一张，还有 GLM-4.6V 系列专门的视觉模型，其中 GLM-4.6V-Flash 免费。）

上手：几乎零成本也能跑

from openai import OpenAI

client = OpenAI(
    api_key=ZAI_API_KEY,
    base_url="https://api.z.ai/api/paas/v4",   # Z.ai 的 OpenAI 兼容端点
)

resp = client.chat.completions.create(
    # 免费档，先拿它把 pipeline 打通再说要不要升级
    # model="glm-4.7-flash",
    # 要便宜 + 能吃视频和文件：
    model="glm-5.3-flash",
    messages=[
        {"role": "system", "content": SYSTEM},
        {"role": "user", "content": question},
    ],
)
print(resp.choices[0].message.content)

我们的建议始终是这条路径：先用 glm-4.7-flash（免费）把整条链路跑通，包括 Prompt、工具调用、错误处理、日志。只有确认这条路走得通，再换成付费档。 反正接口格式一样，换就改一行字符串。

一句话：GLM 是「国内合规 + 开源可私有化 + Coding/Agent 强」的交集点。

什么时候别选 GLM

  • 你的主要问题是「最便宜」 → DeepSeek Flash、Qwen3.8-Flash 都比它便宜。
  • 你要绝对顶格的推理能力 → GLM-5.3 很强，但在自己数据上先做 AB 测，别只看厂商发布的分数。
  • 你的流量大且上下文短 → 记得它是从 32K 就开始分档，而且 2026 年 2 月刚涨过一轮价，做长期预算时把这个趋势算进去。
  • 你极度依赖某家的工具生态（如 Claude 生态的 MCP 外围工具）→ 生态成熟度仍是差距。

炼丹小结

  1. GLM 是这一系列里唯一「主动涨价」的一家（2026 年 2 月，据公开报道涨幅约 30%–83%），这本身就是一个信号：行业从价格战回归价值定价。
  2. 国内站和国际站是两套报价：GLM-5 国内 ¥4/¥18（≤32K）与 ¥6/¥22（>32K），国际站 GLM-5 $1.00/$3.20、GLM-5.3 $1.40/$4.40。
  3. 国内站的阶梯从 32K 就开始——比 Gemini 的 200K、GPT 的 272K 早得多，长请求务必单独核算。
  4. GLM-5.3-Flash（$0.15/$0.50，1M 上下文）是我们扫到的最便宜的「能吃视频和文件」方案。
  5. GLM-4.7-Flash 免费且只有 31B/3B 激活，先把 pipeline 跑通再考虑付费档，是最好的 POC 姿势。
  6. GLM 的三张真牌：开源到可私有化（HuggingFace zai-org）、国内合规完整、Coding/Agent 强项明显。
